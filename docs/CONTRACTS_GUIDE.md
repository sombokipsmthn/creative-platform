# Contracts & Contract Templates - User Guide

## Overview
The Contracts feature allows creators to create, send, and manage professional agreements with clients.

## Creating a Contract

### From Template
1. Navigate to **Contracts** in the admin sidebar
2. Click **New Contract** → **Browse Templates**
3. Select a template (e.g., Photography Services Agreement)
4. Choose client and optional project
5. Map variables (client name, project details, fees)
6. Review and send

### From Quote
1. Open an existing quote
2. Click **Create Contract** button
3. Contract auto-populates with quote details
4. Edit as needed and send

## Client Signing Flow

Clients receive a secure link (e.g., `/contract/[token]`). They can:
- View the contract
- Download PDF
- Accept & Sign
- Decline

Status updates automatically in the admin panel.

## Template Management

### System Templates
12 pre-built templates covering Photography, Video, Design, and General Business.

### Custom Templates
- Save any contract as a template
- Reuse for future projects
- Private to your account

## Status Workflow
Draft → Sent → Viewed → Awaiting Signature → Signed
                                     ↓
                                Declined / Expired / Cancelled

## PDF Generation
Contracts can be downloaded as professional PDFs with:
- Creator branding
- Complete contract terms
- Signature blocks
- Page numbers

## Email Integration
Send contracts via:
- Pre-filled client email
- Custom subject and message
- PDF attachment or link
